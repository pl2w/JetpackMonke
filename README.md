# Jetpack Monke

A mod for Gorilla Tag that gives you a jetpack.

---

## Installation
1. Ensure you have BepInEx 5 installed.
2. Download the latest version from the [Releases](https://github.com/pl2w/JetpackMonke/releases/latest) page
3. Move the mod into your plugins folder.

---

## Usage
Press the designated button to activate the jetpack.
> **Default:** Right controller primary button
> 
---
      
## Configuration
After the first launch, a config file is generated at `BepInEx/config/xyz.pl2w.jetpack.cfg`

| Section | Setting | Default | Description |
|---|---|---|---|
| General | `Input` | `RightControllerPrimaryButton` | Sets the button to activate the jetpack. |
| General | `Force` | `20f` | Sets how strong the jetpack is. |
